# Detection Rules

**Use casual when:**
- Messaging app context (WhatsApp, Discord, Slack DM)
- Mentions friends, family, plans
- Short informal input
- Contains slang

**Use professional when:**
- Email context
- Mentions work, meeting, job, proposal
- Formal input structure
- Has greeting or signature
